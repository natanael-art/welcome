Comunidade Linux
A todos os colaboradores, empacotadores e usuários que fazem o software livre acontecer.
Mainuan é uma distribuição Linux baseada em Ubuntu, com KDE Plasma 6 como ambiente de desktop padrão. Este projeto é software livre e de código aberto. Distribuído sob os termos da GPL v3.
